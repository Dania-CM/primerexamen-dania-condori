# primerexamen-dania-condori

Breve descripción: Soy DANIA CONDORI MARTINEZ, estudiante del segundo semestre de Ingeneria de Sistemas / desarrollador web. Este repositorio contiene la landing responsive y accesible de la empresa MANACO.

## Accesibilidad (a11y)
- Skip link para saltar al contenido principal.
- Foco visible en enlaces y botones (:focus).
- Alt descriptivos en todas las imágenes.
- Navegación posible con teclado (tab).
- Evité usar aria-* innecesarios; usé elementos semánticos.

## SEO
- Título y meta description únicos.
- Open Graph mínimos (og:title, og:description, og:image).
- H1 único y jerarquía correcta (H2 para secciones).
